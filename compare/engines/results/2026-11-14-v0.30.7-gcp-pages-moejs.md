# Render time of tifa pages, moejs session: run 2026-11-14-v0.30.7-gcp-pages-moejs

- Machine: a second GCP t2d-standard-4 session (AMD EPYC 7B13, four cores without SMT, Linux 7.0.0-1017-gcp, linux/amd64) of the same type as the main run, the whole machine held for each run, CPU 0, GOMAXPROCS=1, TZ=UTC, 4 GiB cap. Times are not compared with those of the main run: liustack-quickjs ran again in this session and every ratio is against that run.
- liustack/quickjs v0.30.7 and this comparison at `v0.30.7-8-g449ffb859`, Go go1.27.4, binaries built with `CGO_ENABLED=0 -pgo=off -trimpath`. moejs v0.1.0 with `native/moejs-shim.js` (a `FinalizationRegistry` that never calls back) and core-js for URL, URLSearchParams and the iterator helpers, on its own Intl.
- Bundles from tifa `ba584f71`. One run per engine and page group, 50 warm and 200 timed renders a page for the bench pages, 20 and 100 for MUI and the shop. No run was disturbed (sibling ticks and CPU share in the `.meta` files of the archive). The other engines are not in this session ("not run").
