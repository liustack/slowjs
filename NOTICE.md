## Code and data that go-intl took from other projects

go-intl's own [LICENSE](internal/gointl/LICENSE) names the Unicode License V3, for its code, for the data it made from Unicode's and ICU's, and for code adapted from ICU4C and ICU4X. Its [SOURCES.md](internal/gointl/SOURCES.md) says that it also took code and data from V8 and from the Rust crates that Temporal in Node is built from, at the versions Node v26.10.0 pins. Those ports are modified works: Go written from the C++ or the Rust and changed to fit go-intl, and SOURCES.md says what is ported from which project, at which version. The notices of those projects are in `internal/gointl/qjsdata/`, each copied unchanged from the project at that version, after a short note of ours on what it covers. They sit there, next to the packs whose data they cover.

For temporal_rs, temporal_capi and timezone_provider this module takes the MIT license, one of the two they offer.

## Go modules a program links

A program that imports `github.com/liustack/beastjs` (or its `intl`, `temporal`, `url`, `fmt` or `tifa` packages) links one module besides this one: golang.org/x/sys v0.48.0, on every target, under BSD-3-Clause (`go list -deps` for linux/amd64 and darwin/arm64 shows it, and its license was read from the module's files at the version in `go.mod`). The other requirement of `go.mod`, golang.org/x/arch, is used only by the generator in `internal/goasm/gen` (BSD-3-Clause). `compare/` is a module of its own, and no program that uses this module links it. Its benchmarks link, besides this module and the modules above: github.com/dop251/goja (MIT), github.com/fastschema/qjs v0.0.6 (MIT, with `qjs.wasm`, QuickJS built for WebAssembly, which its README credits to QuickJS and QuickJS-NG), and the modules those two need, at the versions in `compare/go.mod`. `compare/engines`, the comparison with the other pure Go engines, is a module of its own as well, and no program that uses this module links it either (see its `go.mod` and [tifa bundle notices](compare/engines/tifa/THIRD_PARTY_NOTICES.md)). Native reference engines and tools are fetched only at build time, not shipped here: see `native/build.sh` in [Run it again](compare/engines/README.md#run-it-again).

None of the code a program links is under a copyleft license. The one MPL-2.0 part, `internal/arewefastyet/`, is used only by `compare/engines`.

## What a program that ships a binary must include

A program built with this module and given to others as a binary has to reproduce these notices in its documentation or in other materials that come with it, such as a licenses page or a `NOTICE` file:

- **BSD-3-Clause** says that a redistribution in binary form must reproduce the copyright notice, the list of conditions and the disclaimer. Include the text of [LICENSE-TLSF](LICENSE-TLSF) (TLSF, the allocator inside the engine) and the BSD-3-Clause license file of golang.org/x/sys.
- **musl**, the string and math functions of the small libc inside the engine: include [engine/libc/COPYRIGHT](engine/libc/COPYRIGHT) whole. It holds musl's MIT license and its list of the code under other terms. The math files keep the notices of Sun Microsystems, FreeBSD msun and Arm in their headers.
- **MIT** says that the copyright notice and the permission notice must be included in all copies or substantial portions of the software. Include [LICENSE](LICENSE) (liustack/beastjs) and [LICENSE-QUICKJS](LICENSE-QUICKJS) (QuickJS).
- **If the program imports `intl`**, it embeds the locale data, and the Unicode License V3 says its copyright and permission notice must appear with all copies of the data or in the documentation. Include [intl/LICENSE-DATA](intl/LICENSE-DATA), which holds that notice and the notices of ICU's data and Chromium's changes to it.
- **`internal/gointl`** is linked by `intl`, which imports `internal/gointl` and `internal/gointl/temporal`. A program that imports `intl` has to include, in the same way, [internal/gointl/LICENSE](internal/gointl/LICENSE), and from `internal/gointl/qjsdata/` [NOTICE-ICU](internal/gointl/qjsdata/NOTICE-ICU), [NOTICE-ICU4X](internal/gointl/qjsdata/NOTICE-ICU4X) and [NOTICE-TEMPORAL](internal/gointl/qjsdata/NOTICE-TEMPORAL), and [NOTICE-V8](internal/gointl/qjsdata/NOTICE-V8), which every program that imports `intl` links through `internal/gointl/temporal` (see [the table above](#code-and-data-that-go-intl-took-from-other-projects)). Apache-2.0, under which calendrical_calculations comes, asks that recipients get a copy of the license text, which NOTICE-ICU4X holds. A build with the `beastjs_intl_nocjdict` tag leaves the Chinese and Japanese dictionary out, but `core.bin` still holds the other four, so the whole of NOTICE-ICU is still needed.
- **If the program imports `temporal`**, it imports `intl` too, and needs the notices of the two items above. The data and code it takes from go-intl are covered by the same notices: ICU's zones, the tables of icu_calendar and timezone_provider, and the ports of temporal_rs, ICU4X's crates and V8.
- **If the program imports `tifa`**, it imports `intl`, `temporal` and `url`, and needs the notices those three need (their items here).
- **If the program imports `url`**, it links `internal/whatwgurl`: what remains of nlnwa/whatwg-url under Apache-2.0, which asks that recipients get a copy of the license (nlnwa/whatwg-url has no NOTICE file), and the IDNA and Bidi code of golang.org/x/net and golang.org/x/text under BSD-3-Clause, whose binary clause applies. Include [internal/whatwgurl/LICENSE-WHATWG-URL](internal/whatwgurl/LICENSE-WHATWG-URL) and [internal/whatwgurl/LICENSE-GO](internal/whatwgurl/LICENSE-GO). Those two modules are not linked: the code was copied into this one.
- **Go itself.** The Go toolchain links the Go standard library and runtime into every Go program, under Go's own BSD-3-Clause license, which is separate from this module. Its binary clause applies as well: include Go's `LICENSE`, which is in the root of the Go distribution (`$(go env GOROOT)/LICENSE`). The package `fmt` of this module carries code of Go's `fmt` and `math/big` under the same license, which [fmt/LICENSE-GO](fmt/LICENSE-GO) holds, so that text covers it too.
